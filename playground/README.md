# Playground Directory

This directory contains experimental and testing applications.

## 🧪 Experimental Applications

### 1. **app.py** - Image Generator Playground
**Status**: 🧪 Experimental  
**API**: Z.AI CogView-4  
**Purpose**: Test image generation API

**Features**:
- 🎨 CogView-4 model testing
- 🖼️ Image generation with prompts
- 📊 API response analysis
- 🔧 Parameter testing

### 2. **video_app.py** - Video Generator Playground
**Status**: 🧪 Experimental  
**API**: Z.AI CogVideoX & Vidu  
**Purpose**: Test video generation APIs

**Features**:
- 🎬 CogVideoX model testing
- 🎥 Vidu model testing
- ⏱️ Async task tracking
- 📹 Video generation monitoring

## 🚀 Usage

### Image Generator
```bash
streamlit run playground/app.py
```

### Video Generator
```bash
streamlit run playground/video_app.py
```

## ⚠️ Important Notes

- **Experimental**: These are testing applications
- **API Keys**: Require Z.AI API keys
- **Stability**: May have bugs or incomplete features
- **Purpose**: For API testing and development only

## 🔄 Development

Use these playground apps to:
- Test new API features
- Debug API responses
- Experiment with parameters
- Develop new functionality

## 📝 Integration

Features tested in playground may be integrated into production apps in `/apps/` directory.
